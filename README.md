# 📝 Micro Notes App

The **Micro Notes App** is a simple and responsive web application built using **HTML, CSS, and JavaScript**. It allows users to create, edit, and delete notes efficiently. The application stores notes in the browser using **Local Storage**, ensuring that data remains available even after refreshing or reopening the browser.

---

## 🚀 Features

* Create new notes
* Edit existing notes
* Delete notes
* Automatic saving with Local Storage
* User-friendly interface
* Responsive design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
